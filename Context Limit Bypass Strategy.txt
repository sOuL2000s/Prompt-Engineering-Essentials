# 🔥 MASTER PROMPT — Multi-File Codebase Chunk Summarizer

Use this for every chunk you send.

---

## 📌 Prompt

```
You are analyzing PART of a large multi-file codebase.

The input contains MULTIPLE FILES in this format:

--- START FILE: filename ---
<code>
--- END FILE: filename ---

Your task is NOT to summarize casually.
Your task is to extract structured technical memory that allows full architectural reconstruction later.

CRITICAL RULES:
1. Respect file boundaries.
2. Do NOT merge files conceptually.
3. Preserve cross-file dependencies.
4. Be concise but technically dense.
5. Avoid generic explanations.
6. Do NOT rewrite code.
7. Assume more parts are coming later.

Return output in this exact structure:

==================================================

# CHUNK SUMMARY

## A. Files Detected
List all filenames found in this chunk.

--------------------------------------------------

For EACH file, provide:

# FILE: <filename>

## 1. File Responsibility
- Purpose in overall system

## 2. Key Components
List:
- Classes
- Major functions
- Constants
- Configurations
- Exported elements

For each function/method include:
- Name:
- Inputs:
- Output:
- Side effects:
- Core logic (3–6 dense bullet steps):

## 3. Dependencies
- Imports from other local files
- External libraries
- APIs / DB / Services used

## 4. Data Flow
- What enters this file?
- What leaves this file?
- Shared/global state?

## 5. Important Logic
- Critical conditionals
- Error handling
- Security concerns
- Performance considerations

--------------------------------------------------

## B. Cross-File Relationships (Within This Chunk Only)
- Which files interact?
- Function calls across files?
- Shared models/types?

--------------------------------------------------

## C. Global Memory Extraction (VERY IMPORTANT)

Provide a compressed architectural memory block for THIS CHUNK.

Format:

CHUNK_MEMORY:
- bullet points only
- extremely dense
- preserve:
    - module roles
    - service layers
    - DB models
    - API routes
    - shared utilities
    - event flows
- no filler
- no explanations

This will later be merged with memory from other chunks.

==================================================

Do NOT provide loose summaries.
Extract reconstructable system memory.
```
